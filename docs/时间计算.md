# 时间计算

> 关联代码：`common/window.go`、`store/es.go`（时间戳解析）

本系统一律采用 **Unix 毫秒** 作为内部计算单位，时间范围统一为 **左闭右开 `[start, end)`**。

## 1. 基础概念

| 术语 | 含义 |
|---|---|
| 窗口 interval | 由 `sync.interval`（秒）决定，毫秒 `intervalMs = interval * 1000`，默认 10000 |
| lag | ES 写入延迟补偿，毫秒 `lagMs = lag * 1000`，默认 60000 |
| 对齐 | 从 Unix 0 点起按 interval 取整 |
| `TimeRangeMs` | `{startMs, endMs, start, end}`，start/end 为格式化的可读字符串 |

## 2. 对齐函数

统一以毫秒向下对齐：

```
AlignFloorMs(ms) = ms - ms % intervalMs
AlignCeilMs(ms)  = AlignFloorMs(ms) == ms ? ms : AlignFloorMs(ms) + intervalMs
```

- `AlignCeilMs`：向上取整，已在边界则保持不变。

## 3. 上一已结束窗口

```
PrevWindowMs(refMs, intervalMs):
    endMs   = AlignFloorMs(refMs)          // 向下对齐
    startMs = endMs - intervalMs
    返回 [startMs, endMs)
```

示例：`interval=10s`，基准 `23:26:31` → end=`23:26:30`，窗口 `[23:26:20, 23:26:30)`。

## 4. 增量窗口（IncrementalWindow）

```
基准 refMs = nowMs - lagMs
窗口        = PrevWindowMs(refMs, intervalMs)
```

即取 **早于 (now - lag) 的最近一个已结束窗口**，避免读到 ES 尚未写完的数据。

示例：`interval=10s, lag=60s`，now=`23:27:31` → 窗口 `[23:26:20, 23:26:30)`。

## 5. 窗口切分（SplitWindowsMs）

把 `[rangeStart, rangeEnd)` 切成等长 `interval` 的窗口序列：

```
startMs = AlignFloorMs(rangeStart)
for cur = startMs; cur < rangeEndMs; cur += intervalMs:
    nxt = min(cur + intervalMs, rangeEndMs)
    push [cur, nxt)
```

- 所有窗口左闭右开，末尾不足一个 interval 的按实际结束截断。

## 6. 入参时间解析（ParseTimeInput）

支持以下格式（多格式按顺序尝试）：

1. 纯数字 → 视为**毫秒**时间戳
2. `2006-01-02 15:04:05.000`
3. `2006-01-02 15:04:05`
4. `RFC3339Nano`
5. `RFC3339`

## 7. 补全计划边界（CalcBackfillPlan）

```
rangeStartMs = AlignFloorMs(startMs)

若带 end:        rangeEndMs = AlignCeilMs(endMs)
否则(无 end):    rangeEndMs = PrevWindowMs(nowMs - lagMs).endMs   // 截止到当前 lag 边界

windows = SplitWindowsMs(rangeStartMs, rangeEndMs, intervalMs)
TotalWindows = len(windows)
```

> 范围补全（`/sync/backfill`）调用时传 `intervalSec = store.BackfillBaseIntervalSec = 600`（10 分钟初始窗口）；窗口补全不走本函数。

## 8. 对比时间范围（CalcCompareRange）

| 入参 | 行为 |
|---|---|
| start、end 均空 | **上一个整点小时** `PrevClockHourWindow(now)` |
| 仅 start | `[AlignFloor(start), AlignFloor(start)+interval)` |
| start + end | `[AlignFloor(start), AlignCeil(end))`（end 需 > start） |

`PrevClockHourWindow`：取当前时刻所在小时的整点为结束，再往前 1 小时为开始。  
例：`13:45` → `[12:00:00, 13:00:00)`；恰好 `13:00:00` → `[12:00:00, 13:00:00)`。

## 9. 时间戳解析（ES）

`parseESTimestamp` 兼容多种来源：

- 字符串：`RFC3339Nano` / `RFC3339` / `2006-01-02T15:04:05.000Z` / `2006-01-02 15:04:05`
- 数值：毫秒（约 13 位，`>1e12`）直接用；秒级（`<1e12`）`*1000`

## 10. 换算速查（interval=10s）

| now | (now - lag) 对齐 | 窗口 [start, end) |
|---|---|---|
| 23:27:31 | 23:26:30 | 23:26:20 ~ 23:26:30 |
| 23:31:00 | 23:30:00 | 23:29:50 ~ 23:30:00 |
| 23:59:59 | 23:58:59 → 23:58:50 | 23:58:40 ~ 23:58:50 |
